# Сервисный кейс: Котел не зажигается

## Возможные причины

- нет газа
- нет питания
- ошибка розжига
- проблема с платой
- проблема с датчиками

## Что уточнить

- есть ли код ошибки
- есть ли питание
- работает ли плита
- какая модель котла

## Что говорить клиенту

Для точной диагностики нужна модель котла и код ошибки.
