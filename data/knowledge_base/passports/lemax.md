# Лемакс

Основные серии:

Classic
Premium

Classic:
- бюджетная серия
- энергонезависимые напольные котлы
- для простой замены старых АОГВ

Premium:
- серия выше классом
- улучшенное исполнение
- чаще продается клиентам, которые хотят более надежное решение

Важно:
Технические характеристики необходимо сверять по конкретной мощности.
