# Общие правила работы с браком

## Главное правило

Не обещать клиенту замену до подтверждения гарантийного случая.

## По котлам

Запрашивать:

- фото шильдика
- серийный номер
- описание ошибки
- фото подключения
- код ошибки при наличии

Часто требуется авторизованный сервисный центр.

## По газовым колонкам

Запрашивать:

- модель
- серийный номер
- описание неисправности
- фото оборудования

Не делать вывод о заводском браке удалённо.

## По насосам

Запрашивать:

- модель
- фото шильдика
- описание неисправности
- видео работы при возможности

## По радиаторам

Запрашивать:

- фото повреждения
- фото упаковки
- фото маркировки

## По стабилизаторам

Запрашивать:

- модель
- серийный номер
- описание проблемы
- видео индикации

## Важно

Менеджер собирает информацию.

Окончательное решение о гарантийном случае принимает поставщик, производитель или сервисный центр.
