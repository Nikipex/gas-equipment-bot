# Чек-лист менеджера при обращении по браку

Перед тем как обещать клиенту замену:

Проверить:

- кто поставщик
- какой товар
- серийный номер
- есть ли фото
- есть ли видео
- есть ли описание проблемы
- действует ли гарантия
- нужен ли сервисный центр

## Запрещено

- обещать обмен без согласования
- выдавать новый товар без процедуры
- признавать заводской брак самостоятельно

## Правильно

Сначала собрать данные.

Потом отправить поставщику или в сервис.

Только после решения поставщика согласовывать дальнейшие действия.
